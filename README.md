# 공사 3D 시뮬레이터

공동주택 및 복합건축 현장의 공정계획을 3차원으로 검토하기 위한 Python 기반 초기 프로젝트입니다. 기본 예시는 **광주 농성동 지하 4층 탑다운 공사**이며, 실제 도면 수치와 공정표를 입력하면 단계별 시공 상태를 비교할 수 있도록 구성했습니다.

## 현재 구현 범위

- 지하 외곽 CIP 흙막이 벽 시각화
- PRD 기둥 및 지하층 슬래브 단계별 표시
- 공정 단계 슬라이더와 구조물 표시 선택
- CSV 공정 데이터 분리
- 단위 테스트와 GitHub Actions 기본 설정

> 현재 모델은 공법 검토용 개념 모델입니다. 구조·흙막이 안전성 검토나 시공 상세도 대신 사용할 수 없습니다.

## 실행

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
pip install -e .
construction-sim
```

브라우저에서 `http://127.0.0.1:8050`을 엽니다.

## 데이터 수정

`data/schedule.csv`의 단계, 기간, 굴착 깊이와 활성 층을 실제 공정표에 맞춰 수정합니다. 현장 평면 크기, 층고, CIP 간격, PRD 위치는 `src/construction_sim/config.py`에서 변경합니다.

## 다음 개발 순서

1. PDF/DWG 기반 좌표 입력 규칙 확정
2. 실제 PRD·기둥·코어 좌표 반영
3. 장비 동선 및 작업구역 충돌 검토
4. 공정표 연동과 4D 재생
5. 토공량·콘크리트량·장비 생산성 산출
