# 실제 현장 데이터 반영 기준

## 우선 확보할 자료

- 흙막이 평면도: CIP 중심선, 직경, 천공 깊이
- 기초 평면도: 기초파일 및 PRD 중심 좌표
- 지하 구조 평면도: 기둥, 코어, 슬래브 오픈부
- 굴착 단면도: 층별 굴착고와 지지체계
- 예정공정표: 작업 시작일, 기간, 선후행 관계

## 좌표 원칙

현장 기준점 하나를 `(0, 0, 0)`으로 정하고 모든 객체를 m 단위로 변환합니다. 도면 축척 이미지에서 임의로 좌표를 추출하면 누적오차가 커지므로, 가능하면 DWG 좌표 또는 구조 그리드 치수를 사용합니다.

## 모델의 용도

이 모델은 공정회의, 장비 동선 검토, 작업구역 간섭 확인을 위한 의사결정 보조도구입니다. 구조계산서, 가시설 안전성 검토서, 시공상세도를 대체하지 않습니다.
